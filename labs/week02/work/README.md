# Week 2 Student Work Area

This directory is reserved for **your Week 2 work** after you fork the public course repository.

Copy the instructor starter files here once from the repository root:

```bash
cp labs/week02/starter/tiny_language.py labs/week02/work/
cp labs/week02/starter/test_tiny_language.py labs/week02/work/
cp labs/week02/grammar-exercises.md labs/week02/work/
```

Then edit the copies in `work/`, not the files in `starter/`.

Do not run the copy commands again after you have started working, because doing so would overwrite your changes.

The instructor will avoid changing student work files in this directory in later upstream releases whenever possible, which helps keep **Sync fork** updates conflict-free.
